# 條號速查（VGA 版）

VGA 版把「查手冊」寫進了玩法：把嫌犯押到拘留所登記窗口時，Paul 會問罪名，
你得在鍵盤上輸入條號。答不出來，遊戲會走到結局訊息「這場遊戲維護法律，夥伴。
找到你的文件後再回來吧。」

條號原本印在原版包裝內的說明書上。這份是中譯對照，方便沒有實體手冊的玩家把遊戲跑完。
原版 AGI 沒有這種檢查，不需要這張表。

## 置物櫃密碼：269

更衣室置物櫃的三位數密碼是 **269**。

遊戲只告訴你「密碼就是 Grunters 對 Sows 季後賽決賽的最終比分」，轉錯了還會提醒你
「最好再查查你的《公報》」。那份《Lytton 公報》是原版盒裝裡的實體報紙，比分不在
遊戲資料裡——整包 message 資源掃過，Grunters 與 Sows 只出現在提示文字本身，
沒有任何一則報導寫出比分。所以這和刑法條號一樣，是查手冊型的關卡。

原版 AGI 沒有這個密碼鎖：抽字表裡 `combination` 一次都沒出現，`WORDS.TOK` 裡也沒有
`269` 這個詞。
